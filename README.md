# RBO v-2.1.0

La mejor forma de llevar tus finanzas y tener control sobros tus ingresos y egresos.

## 🚀 Características

- **Registro de Ingresos:** Controla cada entrada de dinero de forma sencilla.
- **Gestión de Gastos:** Clasifica y monitorea tus consumos diarios.
- **Planificación de Presupuestos:** Crea planes financieros institucionales o personales.
- **Estadísticas Mensuales:** Visualiza tu progreso con gráficos y datos claros.
- **Interfaz Zen:** Un diseño enfocado en la tranquilidad y la claridad visual.

### 🧘 Enfoque Zen

A diferencia de otras apps financieras, **REBO** utiliza una estética "Zen" para reducir la ansiedad del usuario al gestionar dinero. Esto se logra mediante el uso de imágenes de naturaleza, una arquitectura de información limpia y mensajes que refuerzan la tranquilidad del control financiero.
